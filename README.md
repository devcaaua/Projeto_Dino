# 🦖 Jogo do Dinossauro

Um jogo inspirado no clássico dinossauro do Google Chrome, desenvolvido com HTML, CSS e JavaScript.

O objetivo é desviar dos cactos pulando no momento certo e alcançar a maior pontuação possível. Conforme o jogo avança, os obstáculos ficam mais rápidos, aumentando o nível de dificuldade.

## 🎮 Como jogar
- Espaço ou Seta para cima (↑): pular.
- Toque na tela: pular (dispositivos móveis).
- Após o Game Over: pressione Espaço ou toque na tela para reiniciar.

Desvie dos cactos e tente bater seu próprio recorde!

## ✨ Funcionalidades
- Sistema de pontuação.
- Recorde salvo automaticamente no navegador.
- Aumento gradual da velocidade dos obstáculos.
- Detecção de colisões.
- Animação de pulo.
- Controles para teclado e dispositivos móveis.
- Tela de Game Over com opção de reiniciar.
  
## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
  
## 🚀 Como executar o projeto
Faça o download ou clone este repositório.
Abra a pasta do projeto.
Execute o arquivo index.html em seu navegador.
Comece a jogar!

Não é necessário instalar nenhuma dependência.

## 💻 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos de desenvolvimento web, como manipulação do DOM, eventos em JavaScript, animações com CSS, lógica de programação e armazenamento de dados utilizando localStorage.
